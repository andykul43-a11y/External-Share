# Deploy Capital Gains Calculator to Vercel

## Quick Deployment Guide

Your Capital Gains Calculator is ready to be deployed to Vercel for external sharing! Follow these simple steps:

### Option 1: Deploy Directly from Vercel Dashboard (Recommended)

1. **Go to Vercel:** https://vercel.com/login
2. **Import Project:**
   - Click "Add New..." → "Project"
   - Select "Import Git Repository"
   - Enter: `https://github.com/andykul43-a11y/External-Share.git`
   - Click "Import"

3. **Configure Project:**
   - **Project Name:** `capital-gains-calculator` (or your preferred name)
   - **Framework Preset:** Other (since it's a static site)
   - **Root Directory:** Leave default
   - Leave other settings as default

4. **Deploy:**
   - Click "Deploy"
   - Wait for deployment to complete (usually 2-3 minutes)
   - You'll get a public URL like: `https://capital-gains-calculator.vercel.app`

### Option 2: Deploy Using Vercel CLI

```bash
# Install Vercel CLI globally (if not already installed)
npm install -g vercel

# Navigate to project directory
cd "/workspace/.claude/Capital Gains"

# Deploy to production
vercel --prod
```
